# MonkeyPedia

Welcome to MonkeyPedia, a React application for cataloging information about monkeys. This project is a full-stack application built using React for the frontend and Manifest for the entire backend.

## Features

- **User Authentication**: Researchers can sign up and log in to manage data.
- **Monkey Catalog**: View a public list of all monkeys in the database.
- **CRUD Operations**: Authenticated researchers can create new monkey entries. They can only edit or delete entries they have personally created.
- **Image Uploads**: (Managed via the Admin Panel) Add photos for each monkey.
- **Role-Based Access**: A pre-configured Admin role has full access via the auto-generated Admin Panel.
- **Health Check**: A status indicator shows if the frontend is successfully connected to the Manifest backend.

## Backend by Manifest

This application's backend is powered entirely by Manifest. The `manifest.yml` file defines the data schema, relationships, and access policies.

- **Entities**: `User` and `Monkey`.
- **Authentication**: The `User` entity is `authenticable`.
- **Authorization**: Policies restrict create, update, and delete operations based on user roles and data ownership (`condition: self`).
- **Admin Panel**: A complete admin dashboard is automatically generated by Manifest and is available at `/admin`.

## Getting Started

### Prerequisites

- Node.js and npm
- A running Manifest backend instance

### Frontend Setup

1.  **Install dependencies**:
    ```bash
    npm install
    ```

2.  **Configure Environment Variables**:
    Create a `.env.local` file in the root of the project and add your Manifest backend URL:
    ```
    VITE_BACKEND_URL=https://your-manifest-backend-url.vercel.app
    ```

3.  **Run the development server**:
    ```bash
    npm run dev
    ```
    The application will be available at `http://localhost:5173`.

### Default Credentials

- **Admin**: `admin@manifest.build` / `admin`
- **Demo Researcher**: `researcher@manifest.build` / `password` (You may need to create this user via the signup page or Admin Panel first).
